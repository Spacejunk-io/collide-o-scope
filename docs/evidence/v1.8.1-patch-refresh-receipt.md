## Windows build-helper correction

Windows PowerShell 5.1 can replace or clear `$LASTEXITCODE` when a native
`ffmpeg -version` or `ffprobe -version` invocation is piped directly into
`Select-Object -First 1`. The v1.8.1 helper captures the complete native output
and its exit code first, then selects the display line. A source-level contract
test rejects restoration of either unsafe pipeline.

The corrected helper accepted the installed exact FFmpeg 9.0.1 shared SDK and
completed `scripts/build-windows.ps1 -Release`. This fixes the false rejection
of Gyan's valid `9.0.1-full_build-www.gyan.dev` version string; it does not
change decoding, encoding, or shipped runtime behavior.
